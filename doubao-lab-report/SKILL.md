# Doubao Lab Report

## 概述

本 Skill 用固定的西南大学实验报告模板（`assets/实验报告模板.docx`）作为底稿，把用户每次提供的实验手册与待填内容，自动填成一份可交付的 Word 实验报告。可反复用于多次实验报告任务。

## 使用流程

### 第 1 步 · 读取输入，提炼五栏内容

先完整读取用户提供的实验手册（PDF/DOCX）与「要放上去的东西」（任务清单图片、截图、封面信息等），结合对话上下文，提炼出五栏内容：

- **实验项目名称**：本次实验的主题名（如「预制体与委托事件」）。
- **实验类型**：勾选项，可为 `验证性` / `设计性` / `综合性` 中一个或多个。
- **实验目的**：本次实验要达到的目标（1~2 段）。
- **实验内容及过程**：按实验步骤分小节，小节标题设为加粗（如「（一）预制体的创建与实例化」），步骤正文为非加粗要点。
- **实验分析及总结**：主要收获 + 遇到的问题及解决。

> 注意：只填写能溯源到手册或用户陈述的内容，不要编造用户未做的步骤。用户实际遇到的报错可如实写入「问题及解决」。

### 第 2 步 · 准备内容 JSON

把五栏内容写成一份 JSON 文件，结构如下：

```json
{
  "project_name": "实验项目名称",
  "experiment_type": ["验证性"],
  "purpose": ["实验目的段落1", "段落2"],
  "process": [
    ["（一）加粗小标题", true],
    ["1. 正文要点（非加粗）", false]
  ],
  "analysis": [
    ["1. 加粗小标题", true],
    ["（1）正文要点（非加粗）", false]
  ]
}
```

列表项 `[文字, true/false]` 的第二个值控制是否加粗。`process` 和 `analysis` 均接受纯字符串（非加粗）。

### 第 3 步 · 运行填写脚本

```bash
python3 <本skill>/scripts/fill_report.py \
  --template <本skill>/assets/实验报告模板.docx \
  --content /路径/内容.json \
  --output /交付目录/实验报告-<主题>.docx
```

脚本会定位模板主表并填入五栏，`--output` 放到用户的项目目录。

### 第 4 步 · 复用 word skill 校验

本 Skill 不重复实现校验，必须复用 `word` skill 的读取与审计脚本：

1. **回读核验**：用 `word` skill 的 `scripts/read.py` 读取生成的 docx（维度 0），确认五栏内容正确落入对应单元格。
2. **审计**：用 `word` skill 的 `scripts/audit.py` 校验：

```bash
python3 <word-skill>/scripts/audit.py audit <输出.docx> --source <本skill>/assets/实验报告模板.docx
```

退出码为 0 才可交付；退出码 1/2 时修复后重跑。

### 第 5 步 · 交付

用 `present_files` 交付填好的 Word 文件，`name` 以 `.docx` 结尾。回复保持简短。

## 资源

- `assets/实验报告模板.docx`：西南大学实验报告固定模板（封面 + 主表五栏 + 教师评阅表），作为填写底稿，勿改动。
- `scripts/fill_report.py`：参数化填写脚本，读取内容 JSON 并填入模板主表。
