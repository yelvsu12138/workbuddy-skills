# 前端简历修改工具

## 概述
这是一个用于修改前端简历的技能，支持多种格式的简历文件编辑。可以帮助你快速更新个人信息、技能列表、项目经验、教育背景等内容。

## 支持的文件格式
- **Markdown (.md)**: 使用 Markdown 格式编写的简历
- **HTML (.html)**: 使用 HTML 格式编写的简历
- **JSON (.json)**: 使用 JSON 格式结构化的简历数据

## 功能特性
1. **智能解析**: 自动识别简历文件格式并解析内容
2. **部分更新**: 只修改指定的部分，保持其他内容不变
3. **批量更新**: 支持同时修改多个字段
4. **格式保持**: 修改后保持原有的格式和样式
5. **备份功能**: 修改前自动创建备份文件

## 使用方法

### 基本用法
```
请帮我修改简历中的工作经历
```

### 具体示例
```
1. 更新我的手机号码为 13800138000
2. 添加一个新的项目经验：VisAid 视障辅助应用
3. 更新技能列表，添加 React 和 TypeScript
4. 修改教育背景的毕业时间为 2026 年
```

## 操作流程
1. **读取简历**: 使用 Read 工具读取简历文件
2. **解析内容**: 根据文件格式解析简历结构
3. **执行修改**: 根据用户要求修改指定部分
4. **保存文件**: 使用 Write 或 Edit 工具保存修改
5. **创建备份**: 保存修改前的版本作为备份

## 注意事项
- 修改前请确认简历文件路径
- 建议先查看简历内容再进行修改
- 重要修改建议先创建备份
- 对于 HTML 格式，注意保持标签结构完整

## 工具依赖
- Read 工具：读取简历文件
- Write/Edit 工具：修改和保存文件
- Bash 工具：创建备份和文件操作
